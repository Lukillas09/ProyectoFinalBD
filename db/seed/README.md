# Datos de prueba y carga

Este directorio queda reservado para catálogos reales, archivos CSV y scripts reproducibles de carga masiva de una etapa posterior.

Todavía no se generan datos: antes deben existir el modelo aprobado, las restricciones y una estrategia documentada de carga. Los scripts futuros usarán semilla fija y validaciones de coherencia.
